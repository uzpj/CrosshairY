## Image & Keybinds Update

Download `CrosshairY.exe` below and run it. No installer needed. Requires the [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) if not already installed.

### What's new in v1.0.8

- **Custom image crosshairs 🎉** - import your own PNG/JPG/BMP/GIF images, use them as crosshairs with the existing size and opacity controls, and drag them anywhere on screen. Image positions are saved per profile and work with follow-cursor mode.
- **Crosshair hotkeys** - instantly switch between your favorite crosshairs with custom keybinds. Bind any template, drawn, or image crosshair to a key, complete with live previews, and all bindings persist across profiles.
- **Improved overlay reliability** - the overlay now periodically reasserts its topmost state, helping it stay visible in games that occasionally force other windows above it.
- **Drag positioning for every crosshair** - the drag-to-position tool now works with template, drawn, and image crosshairs instead of image crosshairs only.
- **UI polish** - added the CrosshairY icon to the title bar and made small spacing improvements throughout the application.
- **Various bug fixes and polish**
